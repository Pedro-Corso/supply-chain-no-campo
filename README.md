
# Supply Chain no Campo 

Dashboard inteligente para monitoramento em tempo real (atualização a cada 5 min) de preços de comodities, indicadores CEPEA e notícias globais de logística e agronegócio.

## 🚀 Funcionalidades Principais

-   **Monitoramento CEPEA**: Cotações diárias de Soja, Café, Açúcar, Boi, Milho, Trigo, etc.
-   **Feed de Notícias Global**: Integração via RSS com Valor Econômico, G1, Notícias Agrícolas, Canal Rural, BCB, Portos e Navios, McKinsey e SupplyChainBrain.
-   **Filtro Inteligente**: Motor de busca em tempo real para filtrar notícias por palavras-chave.
-   **HUD de Comodidades**: Sidebar fixa com links diretos para as fontes oficiais do CEPEA.
-   **Exportação Rápida**: Botão para copiar o resumo diário de preços formatado para compartilhamento.

## 🛠️ Tecnologias Utilizadas

-   HTML5 (Semântico)
-   CSS3 (Vanilla com Custom Properties e Glassmorphism)
-   JavaScript (ES6+)
